
This folder contains the Custom Resource Definitions (CRDs) that are generated by the chart.
The subfolder `configuration-crds` contains CRDs related to configuration resources.
The CRDs of this folder are not directly applied to the cluster, as they are not in the chart folder.
Indded, CRDs are automatically generated from OAS (OpenAPI Specification) files and applied by OASGen Provider.
This folder serves as a reference for the CRDs and is included here for documentation purposes only.
